# Simon Game 🎮

A classic Simon memory game with colorful patterns and sounds to test your recall skills, built using **HTML, CSS, and JavaScript**.

Live Demo: https://garvit-agrawal7.github.io/Simon-Game/

---

## How the game works

- The game shows a sequence of colored button flashes, starting with a single color.
- On each level, the sequence grows by one additional random color.
- The player must repeat the exact sequence by clicking the buttons in the correct order.
- If the player makes a mistake, the game ends and they can restart from level 1.

This project is great for practicing DOM manipulation, event handling, and basic game logic in vanilla JavaScript.

---

## Tech stack

- **HTML** – Page structure and game layout.
- **CSS** – Styling, colors, and button animations. 
- **JavaScript** – Core game logic, random sequence generation, input checking, and sound playback. 

---

## Features

- Dynamic sequence generation with increasing difficulty per level.
- Visual feedback using button flashes and CSS classes. 
- Audio feedback for each button press using sound files in the `sounds/` folder. 
- Game over state with the ability to restart quickly.
